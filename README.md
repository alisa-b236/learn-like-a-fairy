# ✨ Learn Like a Fairy — הדמיות אינטראקטיביות בפסיכולוגיה פיזיולוגית

אוסף הדמיות לימודיות אינטראקטיביות בעיצוב פסטלי לקורס **פסיכולוגיה פיזיולוגית**:

1. **המיספרות ואונות המוח — מבנה ותפקוד**:
   - ארבע אונות המוח (אוקסיפיטלית, טמפורלית, פרונטלית, פריאטלית) עם סימון צבעוני ואייקונים מונפשים לתפקידי כל אונה.
   - מסלולי ההצלבה בגוף (קונטרלטרלי), חוש הריח (איפסילטרלי – ללא הצלבה), ומסלולי שדות הראייה ותצלובת העצבים (Optic Chiasm).
   - מנגנון ה״גיבוי״ המרחבי של המיספרה ימין והזנחת צד (Hemispatial Neglect), לצד ראייה עיוורת (Blindsight) ואפזיה (Aphasia).
2. **הדמיית מוח חצוי (Split-Brain Simulation)**:
   - הדמיה אינטראקטיבית של ניתוק הקורפוס קולוסום והפיצול בין תפיסה חושית, דיווח מילולי ופעולה מוטורית ב-6 תרחישי מעבדה.
